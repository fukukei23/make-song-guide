# make-song-guide

AI作曲エンジン教科書 — 任意ジャンルの曲＋歌詞を体系化する、AI音楽クリエイター向けの公開ノウハウ集。

生成AI（MiniMax music-2.6 等）で**任意のジャンル・テーマ**の楽曲を作るための汎用作曲知見を、リファレンス型の理論体系としてまとめた。知見アーキテクチャ（4象限×5層）→ 基礎理論 → ジャンル別の型 → プロンプト・歌詞技法 → MiniMax実測知見 → 実践フロー → トラブル対応まで。

## ローカル確認
`index.html` をブラウザで開く（外部依存なし・単一ファイル）。

## 構成（9章・アコーディオン）
1. make-songとは（知見アーキテクチャ・4象限・5層・ポータビリティ）
2. 作曲の基礎理論（GMIV・構造×BPM計算・感情曲線）
3. ジャンル別作曲の型（10ジャンル・コード進行・スケール）
4. プロンプト技法（具体語推・楽器2-4個・括弧/コロン記法・1変数テスト）
5. 歌詞技法（韻・発音ルール・音節設計・呼吸ポイント）
6. MiniMax実測知見（圧縮率・声質固定・高音質設定・music-cover）
7. 実践フロー（Phase -1〜5）
8. テーマ別＋トラブル対応（失敗パターンカタログ）
9. 名曲照合エンジン設計（定量分析→名曲DB照合→改善ヒント還元・設計判断4論点・ノイズ特徴量の扱い）
